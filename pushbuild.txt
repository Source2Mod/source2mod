First Source2Mod release: Source2Toolkit renamed and carried on, with SourcePawn plugins (.smx) next to native ones on one API, plugin API 5.
Crash reports name the SourcePawn plugin and function (and dumps carry the plugin block, as Accelerator's do); SourcePawn hot reload on Windows too, debounced on both platforms; GeoLite2 City + Country shipped in shared/; source2mod.net.
Blocked game events are freed after every plugin's FireEvent hook has run (fixes a crash in MultiAddonManager and other FireEvent hooks); CTakeDamageInfo.m_iHitGroupId natives removed.
Drop transmit bits outside the pack unions after CheckTransmit. #2
Menu-key fakes are no longer announced as dormant to players who never received them (everyone could lose the connection while one player spammed a menu); a menu reopened during the fake handover finishes it first.
Runs side by side with CounterStrikeSharp (one free per blocked game event; "/" hides only Source2Mod's own commands); PlayerChat hook point on Host_Say and the player_chat game event, once per chat line; HookConCommand / UnhookConCommand replace RegisterConListener -- plugin API 6, plugins built against 5 need a rebuild; resolved addresses kept; SendNetMessage hooked only while something listens.
After CheckTransmit, the out-of-PVS and dont-transmit sets also hold only entities that get packed. Entities missing from the engine's networkable list are dropped from the transmit set too. This fixes the FATAL ERROR "WriteEnterPVS: GetEntServerClass failed".
Menu-key fakes are no longer deleted by the game: the unowned-weapon cleanup (mp_death_drop_gun 0) and the round restart map cleanup left them out of the snapshot while their handle still went into m_hMyWeapons, the cause of the FATAL "WriteEnterPVS: GetEntServerClass failed".
